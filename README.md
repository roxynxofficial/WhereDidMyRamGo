# WhereDidMyRamGo


**Find what's using your RAM. Understand what's slowing down your PC.**

WhereDidMyRAMGo is a Windows system monitoring application designed to make resource usage easier to understand. Monitor memory and CPU consumption in real time, inspect running processes, and track memory usage over time to identify applications that may be consuming excessive resources.

### Features
- **One-File only source code**
- **Real-time monitoring** — Track RAM, CPU, disk, and network usage.
- **Process insights** — Identify applications consuming the most system resources.
- **Memory history** — Monitor resource usage trends over time.
- **Potential memory leak detection** — Flag sustained memory growth for further investigation.
- **Smart recommendations** — Get clear explanations and practical suggestions based on measured system data.
- **Modern desktop interface** — A polished dark-themed UI built with HTML, CSS, JavaScript, and PySide6.

### Built with

Python 3.11 · PySide6 · psutil · HTML · CSS · JavaScript · Chart.js · SQLite

### Platform

Windows 10 and Windows 11.

*WhereDidMyRAMGo is a system monitoring tool, not a malware detector. Memory growth alerts indicate potential issues and do not prove a memory leak.*
